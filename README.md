# DevOps1.6

Version: v0.0.0

Проект лабораторной работы: учёт гор, альпинистов, групп, восхождений и отчётов.

Быстрый старт: `make setup`, `make migrate`, `make run`.

Проверка работоспособности: `curl http://localhost:8000/health`.

Основные команды:
- `make setup` — первоначальная настройка;
- `make run` — локальный запуск;
- `make test` — автоматические тесты;
- `make quality` — статический анализ и проверка форматирования;
- `make format` — автоматическое форматирование кода;
- `make migrate` — создание таблиц базы данных;
- `make backup` — резервное копирование базы данных;
- `make restore` — восстановление базы данных;
- `make verify` — полный набор локальных проверок;
- `make up` — запуск контейнерного окружения;
- `make down` — остановка контейнерного окружения;
- `make container-check` — проверка кода внутри контейнера.

Правила внесения изменений:
1. Любое изменение начинается с задачи.
2. Запрещается отправлять изменения напрямую в `main`.
3. Каждая функция разрабатывается в отдельной ветке.
4. Перед запросом на слияние необходимо выполнить `make verify`.
5. Запрещено удалять тесты ради успешного прохождения проверок.
6. Запрещено отключать статический анализ без согласования.
7. Секреты не должны попадать в репозиторий.
8. Файл `.env` хранится только локально.
